01 / 输入

实验记录

逐项填写实验记录，由团队Agent按团队规则执行判定并提出下一轮方案。未知项留空，无需先整理JSON或上传先例。

填写后点击右侧“评估并生成下一轮方案”。Agent只接收当前选择的输入方式；每次提交会使用账户额度。

实验编号用于区分记录；未知信息留空，不需要为运行而补填。

反应与反应物

角色由你声明，系统不会根据化学名称推断。选错角色会直接改变能否进入判定；反应确实不属于 Suzuki–Miyaura 时，请如实选择“其他”。

反应物角色当量限量试剂（当量基准）

“限量试剂”同时是当量计算基准；未勾选时当量基准保持未知，系统不自动假设 1.0 当量。

催化剂与配体
催化体系分类（可选，用于档内定位）

这五项由你声明，系统不会根据催化剂名称推断。五项都填写后，固定引擎才能把结果与同档参照并排定位；任一项留空则保持“档位无法判定”。

添加剂（碱 / 酸 / 盐 / 氧化剂 / 还原剂 / 助催化剂…）

不再只有“碱”一个入口：任何加入的试剂都可以按类型登记。用量填当量或 mol% 之一；都没填就按未知处理。

用户目标
